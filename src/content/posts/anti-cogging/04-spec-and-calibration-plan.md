## 전제

- 상전류 센서(션트 2상 또는 3상)와 고분해능 엔코더가 있다.
- MCU는 FPU가 있는 Cortex-M4F/M7급. 부품은 미정.
- 용도는 로봇 관절. 저속 정밀 제어와 토크 제어가 중요하고, 백드라이브와 손으로 미는 상황이 있다.

## 제어 계층과 주기 (초기 권장값)

| 루프                | 주기                | 내용                                                                         |
| ------------------- | ------------------- | ---------------------------------------------------------------------------- |
| 전류 (FOC)          | 20~40 kHz, PWM 동기 | ADC → Clarke/Park → d/q PI + 교차 결합 제거 → 역 Park → SVPWM, 데드타임 보상 |
| 안티코깅 피드포워드 | 전류 ISR 안         | `θ_p` 계산 → `C(θ_p)` 조회 → `i_q,ref`에 더함                                |
| 속도·위치           | 2~10 kHz            | PI/PID, 궤적, 피드포워드                                                     |
| 저속 태스크         | 0.5~2 kHz           | 속도 의존 계수 갱신, 열 모델, 디레이팅, ILC 누적, 진단                       |
| 백그라운드          | –                   | 통신, 파라미터 저장, 캘리브레이션 상태 기계                                  |

전류 ISR의 순서는 이렇게 잡았다.

```c
// 전류 ISR (PWM 동기)
read_phase_currents(&ia, &ib, &ic);          // 오프셋·게인 보정 적용
theta_m = encoder_angle_linearized();         // 0..2π, 선형화 LUT
omega_m = speed_estimate(theta_m);            // PLL 또는 관측기, 부호 있음
theta_p = wrap_2pi(theta_m + omega_m * Td);   // 지연 보상
theta_e = wrap_2pi(p * (theta_m + theta_e_offset) + omega_m * p * Td_comm);
clarke_park(ia, ib, ic, theta_e, &id, &iq);

iq_ff  = anticog_eval(theta_p, omega_m);      // 꺼져 있으면 0
iq_ref = clamp(iq_cmd + iq_ff, -Iq_max, Iq_max);
id_ref = id_cmd;                              // 0 또는 약계자

pi_current(id_ref, iq_ref, id, iq, omega_e, &vd, &vq);
limit_voltage_circle(&vd, &vq, Vbus);
inv_park(vd, vq, theta_e, &va, &vb);
deadtime_comp(&va, &vb, ia, ib, ic);
svpwm(va, vb, Vbus);
log_ring_push(theta_m, omega_m, iq, iq_ref);  // 캘리브레이션·진단용
```

타이밍 예산은 Cortex-M4F 170 MHz 기준으로 LUT 조회 + 선형 보간 0.1~0.3 µs, 고조파 8개 합성 1~2 µs, 속도 의존 계수 갱신(atan·sqrt 각 8회)은 저속 태스크에서 수 µs로 잡았다 [추론, 실측으로 확정].

## 런타임: LUT + 선형 보간, 저장은 푸리에 계수

```c
static inline float anticog_lut(float th) {           // th: 0..2π, M은 2의 거듭제곱
    float x = th * (M / TWO_PI);
    int   j = (int)x;  float lam = x - (float)j;
    int  j1 = (j + 1) & (M - 1);
    return (1.0f - lam) * lut[j & (M - 1)] + lam * lut[j1];
}

float anticog_eval(float theta_p, float omega_m) {
    if (!ac.enabled || !ac.map_valid) return 0.0f;
    float g = ac.gain * fade(fabsf(omega_m));           // 페이드아웃
    float v = (ac.format == AC_LUT) ? anticog_lut(theta_p) : anticog_harm(theta_p);
    return clamp(g * v, -ac.iff_max, ac.iff_max);
}
```

- **하이브리드 저장**: 캘리브레이션 결과를 푸리에 계수(선택한 성분만)로 플래시에 저장하고, 부팅할 때 RAM LUT(`M` = 4096)로 재합성한다. LUT의 속도와 고조파 방식의 잡음 필터링·압축을 함께 얻는다.
- `M ≥ 16·n_max`. 84차의 2배(168차)까지 쓰면 M ≥ 2688 → 4096.
- 메모리: float 3600점 14.4 KB, int16 4096점 8 KB, 고조파 10개 약 80 B.
- 저장 레코드에는 magic과 버전, 모터 시리얼, **엔코더 기준 ID**(장착이나 오프셋이 바뀌면 맵 무효), 캘리브레이션 당시의 전기각 오프셋·온도·속도·방법, CRC32를 넣는다. 플래시 페이지 2개를 번갈아 쓰고, 공장 맵과 학습 맵을 따로 보관해 되돌릴 수 있게 한다.
- LUT 방식에서는 성분별 속도 보정을 못 하므로 `n_k·ω_m ≪ ω_bw` 범위에서 `atan x ≈ x`로 근사해 공통 리드각으로 바꾼다. `θ_p ≈ θ_m + ω_m·(T_d + 1/ω_bw)`. 진폭은 보정하지 않는다.

## 속도 의존 보정과 페이드아웃

전류 루프를 1차로 근사한다. PI를 `K_p = L·ω_bw`, `K_i = R·ω_bw`로 설계해 극과 영점을 상쇄한 경우다.

```text
G_i(s) ≈ ω_bw / (s + ω_bw)
|G_i(jω_k)| = 1 / sqrt(1 + (ω_k/ω_bw)²),    ∠G_i = −atan(ω_k/ω_bw)

A'_k = min( A_k · sqrt(1 + (n_k·ω_m/ω_bw)²),  g_max · A_k )
α'_k = α_k + n_k·ω_m·T_d + atan(n_k·ω_m/ω_bw)
```

- 진폭 보정이 상한에 닿는 속도는 `rpm_max = 60·f_bw·sqrt(g_max² − 1) / n`. n = 84, f_bw = 1 kHz이면 g_max = 2에서 1237 rpm, 3에서 2020 rpm.
- 같은 조건(지연 75 µs)에서 보정하지 않은 피드포워드는 약 1000 rpm부터 리플을 오히려 키운다(잔차 1.18배).
- 페이드아웃: 속도 `ω_1`까지는 1, `ω_2`에서 0이 되게 선형으로 줄인다. 켜고 끄는 문턱에 약 2%의 히스테리시스를 둔다.
- 실제 전류 제어기가 1차 근사와 다르면 실측 주파수 응답으로 바꾼다.
- 전압 한계에 가까운 고속에서는 전류 루프 여유가 없으므로 고조파 전압 피드포워드가 대안이 된다.

## 캘리브레이션

### 선행 조건 (순서가 중요)

1. 전류 센서 오프셋·게인 보정. 오프셋은 전기 1차, 게인 불일치는 전기 2차 리플을 만들고 조건에 따라 변하므로, 맵에 넣지 말고 센서 단계에서 없앤다.
2. 엔코더 선형화와 지연 측정.
3. 전기각 오프셋 정렬.
4. 기계 조건: 무부하, 축에 중력이 걸리지 않게(수평 축 또는 부하 분리), 가능하면 감속기 조립 전, 케이블이나 스프링 토크 없이.
5. 환경: 25 ± 5 °C. 베어링 그리스가 자리 잡도록 몇 분 미리 돌린 뒤 측정하고 온도를 기록한다.

### 방법 A: 정지 유지법

1. 위치 루프 이득을 단단하게 맞추고, 속도 루프에 적분기를 둔다.
2. 목표 위치를 `Δθ = 2π/M_cal`씩 옮기며 정방향으로 한 바퀴 돈다.
3. 각 점에서 위치 오차와 속도가 문턱 아래로 `t_settle` 동안 유지될 때까지 기다린다.
4. `T_avg` 동안 `i_q` 평균을 기록한다. 위치는 명령값이 아니라 **실제 위치**로.
5. 역방향으로 반복한다.

- 시간은 `M_cal × 2 × (t_settle + T_avg)`. 4096점·70 ms면 약 9.6분, 2048점·60 ms면 약 4분.
- 장점: `dω/dt = 0`이라 관성, 대역폭, 데드타임을 신경 쓸 필요가 없다. 가장 깨끗하다.
- 단점: 느리다. 정지마찰 범위 안에서는 어디서 멈추는지 애매해서 정·역 평균이 필수다. 이득이 약하면 끝나지 않을 수 있다.

### 방법 B: 저속 등속 + 관성 보정

1. 속도 루프로 일정한 `ω_cal`을 정·역 각각 `N_rev` 회전 동안 유지한다.
2. `(θ_m, i_q, t)`를 기록한다.
3. 오프라인에서 영위상 미분으로 `ω`와 `dω/dt`를 구하고 `Ĉ_raw = i_q − (J/Kt)·dω/dt`를 계산한다.
4. 각도 칸별로 회전 평균을 낸다.

- 속도는 `n_max·ω_cal ≤ 0.1·ω_c,speed`를 만족하면서 걸렸다 미끄러지는 현상이 없을 만큼은 빠르게. 산업 사례는 1~5 rpm. 속도 루프 대역 50 Hz, `n_max` = 168이면 `ω_cal` ≤ 0.187 rad/s(약 1.8 rpm).
- 검증: 두 속도에서 얻은 맵이 일치하는지 본다.

### 후처리 (공통)

1. 정·역 분리: `Ĉ = (ī_q⁺ + ī_q⁻)/2`, `F̂ = (ī_q⁺ − ī_q⁻)/2`. 부호 규약에 주의한다. 정·역 모두 같은 규약의 `i_q`일 때만 평균이 마찰을 지운다. 반대로 하면 마찰이 남고 코깅이 지워진다.
2. `Ĉ`의 평균을 제거한다(D7).
3. 푸리에 계수: `a_k = (2/M)·Σ_j Ĉ(θ_j)·cos(n_k·θ_j)`, `b_k = (2/M)·Σ_j Ĉ(θ_j)·sin(n_k·θ_j)`, `A_k = sqrt(a_k² + b_k²)`, `α_k = atan2(a_k, b_k)`.
4. 성분 선택: `A_k ≥ κ·σ_k`, κ ≈ 3. `σ_k`는 반복 측정 사이의 표준편차.
5. 고른 성분만으로 LUT를 재합성한다. 잡음이 걸러진다.
6. 차수 점검: 주요 차수가 LCM 이론이나 제조 공차 차수와 맞는지 본다. 기계 1·2차는 엔코더 편심이나 중력, 기계 `p`·`2p`차(전기 1·2차)는 전류 센서 오차, 감속기 주기(파동 발생기의 2배, 4배)도 의심 대상.
7. 메타데이터(온도, 날짜, 방법, 속도, 펌웨어 버전)와 CRC를 붙여 저장한다.

### 검증

- 보상 ON/OFF 비교: 정지 유지 시 `i_q` 리플, 저속 등속 시 속도 리플, 토크 센서가 있으면 토크 리플. 차수별 스펙트럼을 보상 전후로 나란히 적는다.
- 교차 검증: 방법 A와 B의 맵, 두 속도의 맵. 토크 센서가 없을 때의 핵심 검증 수단이다.

## 안전과 예외

- `|i_q,ff| ≤ I_ff,max`. 예를 들어 정격의 20% 이하(미정). 켜고 끌 때는 램프로 바꾼다. 브레이크, 코스트, 고장 상태에서는 0.
- 맵이 무효이면(CRC, 버전, 엔코더 기준 불일치) 보상을 끄고 경고한다.
- 안정성: `C(θ)`는 측정 위치의 함수라서 사실상 국소 강성 `Kt·dC/dθ`를 가진 위치 피드백이다. 맵이 정확하면 코깅의 국소 강성을 상쇄할 뿐이지만, 위상이 어긋나면 국소적으로 음의 강성이 생겨 안정 여유가 줄 수 있다. 고차·대진폭 성분에서 특히 주의 [추론].
- 캘리브레이션 중 보호: 토크 상한, 위치 한계, 타임아웃, 걸림 감지 시 중단.

## 선택 기능

- **부하 의존 항**: 외부 부하를 걸고 `i_q` 수준별(−I, 0, +I)로 맵을 재서 각도별로 회귀한다. `C_ℓ(θ) = C_0(θ) + i_q,ℓ·G(θ)`. 전류에 따라 부호가 바뀌는 부분이 `G`, 바뀌지 않는 부분이 `C_0`. 코깅과 차수가 겹치므로 반드시 `i_q`를 바꿔 가며 분리한다.
- **각도 영역 ILC**: `a_k ← a_k + γ·ã_k`, `b_k ← b_k + γ·b̃_k`. `ã_k`, `b̃_k`는 한 회전 동안 속도·위치 제어기 출력의 `n_k`차 푸리에 계수로, 보상이 완벽하면 0으로 수렴한다. 수렴 조건은 위상 오차 `δ < arccos(γ/2)`(γ = 1이면 60°, 0.3이면 81°). 정속·저가속·부하 과도 없음일 때만 갱신, 소프트 스타트, 공장 맵 보존.
- **마찰 보상**: `T_f = T_c·sgn_s(ω) + B·ω`. 부드러운 부호 함수를 쓰고 이득은 0.5~0.8로 1보다 작게 해서 리밋 사이클을 막는다. 안티코깅 뒤 가장 큰 잔여 원인이다.

| T4  | 부하·온도 의존      | 정격 부하 0/50/100%, 권선 25/80 °C                                                     |

| T6  | 리플 시험 (NEMA)    | 최대 연속 정지 토크로 통전한 상태에서 3 rpm 이하 외부 구동. 측정 대역폭 명시           |
| T7  | 연산 시간           | ISR 사용률 (사이클 카운터)                                                             |

시험대는 측정 주파수를 첫 비틀림 공진의 1/5 이하로, 반력형 토크 센서로, 필터 없이, 1~10 rpm, 양방향 최대 20회전 평균. 센서 영점은 모터를 분리한 상태에서 한 바퀴 평균으로 잡는다.

모터(극쌍수, 슬롯 수, Kt, R, L, J, 정격·최대 토크와 전류, 최대 속도, 자석·절연 등급), 감속기(종류, 감속비, 출력축 엔코더 유무), 엔코더(방식, 비트 수, 인터페이스, 지연, 정확도, 자가 보정 지원), 전류 센싱(션트 구성, ADC 비트, PWM 동기 샘플링), 전력단(버스 전압, 소자, 게이트 드라이버, 데드타임, PWM 주파수), MCU, 제어 요구(모드, 목표 대역폭, 안티코깅 적용 속도 범위, 통신), 사용 조건(부하·온도 범위, 백드라이브), 시험 장비(토크 센서, 다이나모, 온도 챔버), 목표 수치(리플 %, TRR, 연산 예산, 캘리브레이션 허용 시간).

## 지금 상태와 다음

- 역분석 노트, 이론 정리, 조사 보고서, 결정 사항을 하나의 인수인계 문서로 묶어 새 프로젝트로 넘겼다. 처음부터 다시 조사하지 않고 설계와 구현으로 들어가기 위해서다.
- 하드웨어보다 먼저 **Python 시뮬레이터**를 만들기로 했다. 모터(`J`, `Kt`), 코깅 고조파, 마찰, 1차 전류 루프, 지연, 엔코더 양자화와 지연, 속도·위치 루프를 넣고, 방법 A/B와 통합식, 속도 보정을 검증한다.
