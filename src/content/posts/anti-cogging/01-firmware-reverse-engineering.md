_이 시리즈는 11월 12일 새벽에 사흘치 작업을 한꺼번에 정리해 쓴 것이다. 각 글의 날짜는 그 작업을 하던 날이다._

## 배경

로봇 관절용 액추에이터의 모터 제어기 펌웨어를 새로 쓰는 준비를 하고 있다. 코깅 토크 보상(안티코깅)과 코일 온도 추정을 넣고 싶은데, 참고할 구현이 필요했다. 손에 있던 것은 시판 소형 BLDC 모듈(드라이버 일체형)의 펌웨어 바이너리 하나였다. 소스는 없다. 그래서 바이너리를 정적으로 역분석해서 네 가지를 알아보기로 했다.

1. 주변장치 설정과 인터럽트 구조
2. 모터 제어 알고리즘의 종류. FOC인지, 특별한 구성이 있는지
3. 코일 온도 추정 알고리즘이 있는지
4. 안티코깅 알고리즘이 있는지

이 글에는 구조와 아이디어만 적는다. 주소, 메모리 배치, 통신 프로토콜 식별자 같은 세부는 작업 폴더의 노트에만 두었다. 역분석 결과를 어디까지 쓸 수 있는지(저작권, 사용 약관)는 특허와 별개로 확인해야 하는 문제라, 여기서는 제조사의 공개 문서로도 알 수 있는 수준의 동작 원리만 다룬다.

## 어떻게 읽었나

- 벡터 테이블에서 인터럽트 핸들러를 찾고, 타이머와 ADC 레지스터 설정값에서 주기를 계산했다.
- C++로 짜인 펌웨어라 RTTI에 클래스 이름이 남아 있었다. 클래스명으로 각 모듈의 역할을 확정할 수 있었다.
- 변수의 물리적 의미는 동작을 보고 붙였다. 그래서 노트에는 직접 확인한 것에는 **[확인]**, 해석한 것에는 **[추론]** 표시를 붙여 구분했다. 이 표기는 이후 문서에도 그대로 썼다.
- 한 번 틀렸다. 처음에는 ISR을 26 kHz, PWM을 13 kHz로 적었는데, PWM 타이머가 시스템 클럭의 2배로 돈다는 것을 나중에 확인해 **PWM 26 kHz, ISR 52 kHz**로 정정했다. 클럭 트리를 먼저 확정하고 주기를 계산해야 한다는 교훈.

## 발견 1: 전류 센서가 없는 전압 모드

| 항목        | 내용                                                                              |
| ----------- | --------------------------------------------------------------------------------- |
| MCU         | Cortex-M4F급. 그런데 연산은 대부분 Q16 고정소수점과 소프트웨어 double 헬퍼로 한다 |
| PWM         | 센터 정렬 26 kHz, 듀티 분해능 약 2,800단계                                        |
| 제어 ISR    | PWM 카운터의 업·다운 양쪽에서 발생 → 52 kHz                                       |
| 저속 태스크 | 0.5 ms마다 → 2 kHz. 속도 추정, 지연 보상각, 전압 제한, 위치 제어기                |
| 상전류 센서 | **없음**. DC 버스 전류를 변조지수로 나눠 모터 전류를 추정하고 표시용으로만 쓴다   |
| 엔코더      | 자기식 SPI. 하위 비트를 버려 12비트로 사용. 4096점 선형화 LUT가 따로 있다         |
| 구동        | 전압 벡터를 엔코더 전기각으로 회전시키는 방식. d/q 전류 PI 루프가 없다            |

즉 FOC가 아니다. 전압 지령 `V`를 정하고 `m = V / V_bus`를 SVPWM에 넘긴다. 전류 루프가 없으니 인덕턴스 때문에 전류가 전압보다 늦는 것을 **리드각**으로 보정한다. 2 kHz 태스크에서 `R`, `L`, 역기전력 `E = Ke·ω`로 리드각을 계산해 ±45°로 제한하고, 속도에 비례하는 **지연 보상각** `θ_adv = ω · t_lead`(기본 36 µs)도 더한다. 전류 제한은 모델 기반이다. 전압을 `[E − I_max·R, E + I_max·R]` 창 안으로 자르고, 버스 전압 문턱으로 회생 과전압도 막는다.

위치 제어기 출력도 전압이다. 속도 모드는 목표 위치를 적분해서 구현했다.

## 발견 2: 안티코깅은 기계각 사인파 8개의 합

기계각 1회전을 주기로 하는 사인 성분을 **최대 8개(기본 4개)** 더해 전압 지령에 보탠다.

```text
V_cog = Σ_i A_i · sin( n_i · (θ_m + θ_adv) + φ'_i )      (i < N, N ≤ 8)
```

- `n_i`는 1회전당 반복 수(차수), `A_i`와 `φ_i`는 개체별 진폭과 위상이다.
- 사인 값은 4096점 테이블에서 **가장 가까운 점을 읽고 보간하지 않는다**.
- 위상만 속도에 따라 보정한다(2 kHz). `φ'_i = φ_i + atan(n_i · ω · τ)`, `τ` 기본 0.58 ms. 전압 모드에서 전류가 전압보다 L/R 시정수만큼 늦는 것을 위상으로만 보정하는 것으로 읽혔다 [추론]. **진폭은 보정하지 않는다.**
- 지연 보상각 `θ_adv`는 정류와 안티코깅이 같은 값을 쓴다.
- 구동 모드에서만 적용하고 브레이크·코스트에서는 끈다. 결과 전압에도 디레이트와 전압 제한이 그대로 걸린다.
- **보드 안에 캘리브레이션이나 학습 루틴이 없다.** 계수는 공장에서 개체별로 측정해 넣는다. 공개 문서에도 모터마다 고유한 코깅 정보가 공장에서 로드된다고 되어 있다.
- 계수 저장소에 CRC가 없다.
- 공개 문서를 보면 이전 세대는 LUT 방식이었고, 최근에 고조파 방식이 추가됐다.

## 발견 3: 코일 온도 추정기는 2노드 열 모델

코일 `T_c`와 하우징 `T_h` 두 노드를 2 kHz로 적분한다.

```text
G_ca = max(G_ca,min, k_conv·√|ω|)          속도에 따른 대류
Q_ac = (T_amb − T_c)·G_ca                  주변 공기 → 코일
Q_hc = (T_h − T_c)·G_ch                    하우징 → 코일
Q_rh = (T_ref − T_h)·G_hr                  기준(MCU 온도 − 14 °C) → 하우징
P_h  = k_hloss·|ω|                         속도에 비례하는 하우징 발열
T_c += (P_coil + Q_hc + Q_ac)·dt / C_coil
T_h += (P_h + Q_rh − Q_hc)·dt / C_housing
```

- `P_coil = I²·R(T_c)`. `I`는 버스 전류로 추정한 값이고, `R(T)`에 추정 온도가 다시 들어가는 피드백 구조다. `R(T) = R_20·(1 + 0.004·(T_c − 20)) + 배선 저항`.
- 코일 시정수는 수 초, 하우징은 수 분 규모였다.
- 추정 온도의 용도는 네 가지. `R(T)` 보정(전압 창 계산에도 들어감), 출력 디레이팅(MCU 온도 디레이트와 곱함), 안전 차단(한계를 넘으면 fault를 세우고 코스트로 전환), 상태 보고.

[솔레노이드 시리즈](/posts/solenoid/01-why-measure/)에서 권선 저항으로 온도를 재던 것과 같은 아이디어가 모터에도 들어가 있었다. 다만 여기서는 온도를 재는 대신 **모델로 추정**하고, 그 온도로 저항을 보정한다. 상전류 센서가 있는 우리 보드라면 `P_coil`을 측정 전류로 계산할 수 있어 더 정확해진다. 파라미터는 모터별로 다시 맞춰야 하고, 정전류로 가열하며 권선 저항을 재서 온도를 구하는 방식으로 식별할 수 있다. 솔레노이드에서 쓴 방법 그대로다.

## 이 방식의 한계

| 한계                      | 원인                           | 영향                                                          |
| ------------------------- | ------------------------------ | ------------------------------------------------------------- |
| 진폭 감쇠를 보정하지 않음 | 1차 지연을 위상으로만 보정     | τ = 0.58 ms이면 1 kHz 성분의 진폭이 0.26배, 위상은 74.6° 지연 |
| 권선 온도                 | 전압 기준 보상인데 R(T)가 변함 | 60 K 상승 시 R이 약 23.6% 늘어 보상 전류가 약 19% 부족        |
| 부하 의존 리플            | 전류 정보가 없음               | 캘리브레이션 조건과 다른 부하에서 잔차                        |
| 각도 분해능               | 12비트, 보간 없는 사인 테이블  | n차 성분은 한 주기에 4096/n점뿐                               |
| 전압 양자화               | 한 단계 = V_bus / 2769         | 토크 한 단계 = Kt·ΔV/R. 저항이 작은 모터일수록 거칠어진다     |
| 캘리브레이션              | 외부(공장)에 의존              | 개체별 측정 공정이 따로 필요                                  |

우리 모터에는 상전류 센서와 고분해능 엔코더가 있다. 이 한계 표가 그대로 "우리는 다르게 할 수 있는 것" 목록이 됐다. 그 생각을 정리한 과정은 [2편](/posts/anti-cogging/02-harmonics-and-current-mode/)에.
