## 열전대 로거를 직접 읽기로 했다

TES-1384에는 공식 PC 프로그램이 있지만 파일로 저장만 해 주고, 다른 데이터와 묶기 어렵고, USB가 빠졌다 들어오면 다시 잡아 주지 않는다. 측정하는 동안 PC가 받을 수 있는 유일한 데이터가 온도였으므로, 이것부터 내 손에 넣고 싶었다. 프로토콜이 매뉴얼에 공개되어 있어서 Python(pyserial + matplotlib)으로 직접 만들었다.

### 매뉴얼과 달랐던 점

실제 장비에 붙여 보니 매뉴얼대로 안 되는 게 여럿 있었다. 다음에 비슷한 장비를 만질 때를 위해 적어 둔다.

- **DTR/RTS가 켜져 있으면 미터가 아무것도 보내지 않는다.** 포트를 열 때 둘 다 OFF로 열어야 한다.
- **USB를 다시 꽂으면 화면은 켜져 있어도 PC 전송이 멈춘다.** DTR/RTS를 ON으로 한 채 `A`(기록 개수 읽기, 설정은 바뀌지 않음)를 보내고 포트를 닫았다 다시 열면 재개된다. 드라이버가 연결할 때마다 이 깨우기 절차를 자동으로 한다.
- 프레임은 매뉴얼의 8바이트가 아니라 **12바이트**다. `02 S1 S2 S3 F_hi F_lo F_frac 00 00 00 00 03`. 둘 다 파싱되게 했다.
- 요청 없이 스스로 전송하고, **4채널 한 바퀴에 약 3초** 걸린다. 1초 간격으로 기록하면 같은 값이 반복된다.
- Status3의 bit3이 1이면 프로브가 꽂힌 것이다. 빈 채널도 의미 없는 값(예: 78.4 °F)을 보내므로 걸러야 한다.
- 온도는 항상 °F로 온다. 정수부 16비트(음수면 65536 − 값), 세 번째 바이트 하위 4비트가 소수 첫째 자리. 분해능 0.1 °F(≈ 0.06 °C). 0 °F 이하 음수 디코딩은 아직 실측 검증 전이다.

### 자동 재연결

파서는 STX(0x02)/ETX(0x03) 기준으로 재동기화해서 재연결 직후의 반쪽 프레임을 버린다. 연결 관리는 백그라운드 스레드가 한다.

| 상황                                        | 동작                                                       |
| ------------------------------------------- | ---------------------------------------------------------- |
| USB 분리 / 포트 오류                        | 포트를 닫고 2초마다 다시 열기 시도                         |
| 포트는 살아있는데 데이터가 끊김 (미터 꺼짐) | 8초 동안 프레임이 없으면 포트를 재오픈                     |
| 재연결 후 미터가 침묵                       | 포트를 열 때마다 깨우기 절차                               |
| 포트 미지정                                 | USB-Serial 칩 포트부터 차례로 열어 데이터가 오는 포트 탐색 |

실측으로 USB를 뽑으면 즉시 `disconnected`, 다시 꽂으면 약 5초 안에 `connected`로 돌아온다. 끊긴 동안은 이전 값 대신 `None`을 보여 준다. 오래된 값이 살아 있는 것처럼 보이는 게 제일 위험하기 때문이다.

GUI는 실시간 그래프(최근 10분), CSV 기록(한 줄마다 즉시 디스크에), 채널별 보정 계수 실시간 적용(원래 값과 보정값을 함께 저장)을 한다. 공식 프로그램과 같은 COM 포트를 동시에 열 수는 없다.

## 수동 입력 패널: 손으로 적는 값에 시각과 온도를 붙이기

PC로 바로 받을 수 있는 것은 온도뿐이었다. 전원공급기의 V·I는 표시창을 눈으로 읽어야 하고, LCR 미터는 PC 연결 케이블이 없는 데다 통전 중에는 물릴 수도 없어서 따로 재야 했다. 그래서 GUI 아래에 "Manual entry" 패널을 붙였다. 핵심은 하나다. **값을 입력하는 순간의 PC 시각과 열전대 4채널 온도(원래 값·보정값)가 한 줄에 같이 저장된다.** 그러면 손으로 적은 V·I·LCR 값이 자동으로 온도 축 위에 올라간다.

- **Unit ID / probe**: 시험 개체와 그 개체에 붙인 열전대 채널. 입력할 때마다 그 채널 온도가 `T_surface` 열에 저장된다.
- **Power (V, I)**: `R = V/I`, `R/R_ref`, 권선 온도 `T_w = (R/R_ref) × (234.5 + T_ref) − 234.5`를 실시간 계산. **R/R_ref ≥ 1.29(약 100 °C)면 빨간 LIMIT 경고.**
- **LCR (DCR, L, Q, 주파수, 플런저 위치)**: DCR로도 권선 온도 계산(냉각 곡선용).
- **Force**: 측면 하중 단계 + 피크 힘. 그때의 V·I와 위치도 함께.
- **Ripple**: PWM 파형에서 읽은 ΔI_pp 또는 ON/OFF 기울기 → L 실시간 계산. `L = D(1−D)(V_bus − V_sw + V_D) / (ΔI_pp · f)`
- **Event**: Release OK / FAIL / Dropout / Power ON / OFF 같은 빠른 버튼. V·I 칸의 현재 값도 같이 저장된다. 최소 기동·유지 전류 시험용.

그래프에는 입력 시점이 점선으로 표시된다. 마지막 설정은 파일에 남아 다음 실행 때 복원된다.

## 그날 생각이 바뀐 순서

처음엔 권선 온도를 정확히 재고 싶었다. 그런데 코일 표면에 열전대를 붙이기 어려운 구조였고, 물중탕도 당장은 어려웠다. "그냥 표면 온도와의 관계만 구하면 안 되나?" 하다가 질문을 다시 세웠다.

**내가 회로에서 결국 쓸 것은 전류 리플로 구한 인덕턴스와 저항이다.** 표면 온도는 정밀할 필요가 없고 "이쯤이면 위험하다" 정도만 알면 된다. 진짜로 알고 싶은 것은

1. 플런저가 잘 올라왔는지, 아직 박혀 있는지를 리플로 판별할 수 있는가
2. 박혀 있다면 정격 이상의 전압 지령으로 뺄 수 있는가
3. 올라온 플런저가 일정 충격을 버티는 전류·전압은 얼마인가

그래서 그날은 **무전원 상태에서 표면 온도에 따른 LCR 값만** 찍기로 했다. 절차는 상온에서 1시간 이상 방치 → DCR·L·Q(잠금 위치) → 통전으로 데움 → **전류 0 확인 후** 전원 분리, LCR 연결 → 식는 동안 30초~1분마다 DCR / L / Q 입력(표면 온도는 자동 저장). 해제 위치 L은 플런저를 스토퍼로 받친 상태로.

중간에 "LCR 미터에 꽂아 놓고 전원을 물려도 되나?" 싶었는데 안 된다. 대신 **정상상태를 만들면서 전원공급기의 V·I를 읽으면 `R = V/I`로 온도별 저항이 나온다.** 이것이 이날 저녁의 두 번째 측정이 됐다.

## 측정 결과

대상은 S02, S03 두 개체. 열전대는 표면에 붙였고(S02 = T2, S03 = T3), 전원공급기 V·I는 수기 입력, LCR은 무전원에서 1 kHz.

### 위치별 인덕턴스 (무전원, 1 kHz, 표면 약 29 °C)

| 개체         | 잠금 L (mH) | 해제 L (mH)   | 해제/잠금 | DCR (Ω)                            | Q (잠금/해제)    |
| ------------ | ----------- | ------------- | --------- | ---------------------------------- | ---------------- |
| S02          | 6.07        | 14.61 / 14.66 | 약 2.4    | 25.05~25.10 (1회 24.24, 접촉 의심) | 1.21 / 1.31~1.35 |
| S03          | 5.38        | 미측정        | -         | 24.22                              | 1.15 / -         |
| (참고) 10/14 | 약 6        | 약 14         | 약 2.3    |                                    |                  |

위치 차이 약 140%는 온도 영향(약 55 °C에 13%)이나 개체 차이(잠금 L 약 13%)보다 훨씬 크다. 리플로 환산하면(12 V, 20 kHz, D = 30%, `ΔI = D(1−D)V/(L·f)`) **해제 약 9 mA, 잠금 약 22 mA**다. 보드 ADC로 이 둘을 구분할 수 있는지가 다음 판단 포인트가 됐다. 동작 전류에서의 L(포화로 대비가 줄 수 있음), 중간 걸림 위치의 L, 실제 PWM 리플은 아직 모른다.

### 정상상태 열 특성 (8.5 → 3.0 V 단계)

![정상상태 V/I 분석: R vs 표면 온도, 온도차 vs 전력, 표면·권선 온도 vs 전력](@/assets/images/solenoid/steady-1019.png)

권선 온도는 R을 **전력 → 0으로 외삽한 기준 저항**(같은 V/I 방식으로 잰 값)과 구리 α로 계산했다.

| 항목                         | S02               | S03               |
| ---------------------------- | ----------------- | ----------------- |
| 기준 R₀ (P→0, V/I)           | 26.67 Ω           | 25.79 Ω           |
| 주변 온도 (P→0 외삽)         | 29.5 °C           | 29.8 °C           |
| 표면 − 주변                  | 19.7 °C/W         | 21.8 °C/W         |
| 권선 − 표면                  | 19.7 °C/W         | 13.9 °C/W         |
| 권선 − 주변 (합)             | 약 38 °C/W        | 약 33 °C/W        |
| 8.5 V (약 2.1 W) 표면 / 권선 | 67.5 / **109 °C** | 74.5 / **103 °C** |

여기서 이 프로젝트의 첫 번째 굵은 결론이 나왔다.

- 권선 100 °C 이하(주변 30 °C)로 유지하려면 연속 전력은 `70 °C ÷ 33~38 °C/W ≈ 약 2 W`, 전압으로 약 8 V다.
- **12 V 연속 통전은 약 5.4 W라 불가능하다. Hit-and-Hold가 필수다.**
- 고온에서 R이 약 30% 오르므로 전압 지령을 유지하면 전류가 약 25% 준다. 유지 전압은 고온 R 기준으로 정하거나 전류 제어가 낫다.
- 두 개체의 R 차이(약 3.4%)는 LCR DCR 차이와 같은 비율이다. 개체 편차다.
- "권선 − 표면"이 19.7과 13.9 °C/W로 다른 것은 열전대 부착 위치 차이일 가능성이 크다. S03 열전대가 7 °C 높게 읽는데 권선은 S02가 더 뜨겁다.

## 측정 방법에서 확인된 점

이날 배운 것 중 결과보다 오래 남은 것은 이쪽이다.

- **전원공급기 V/I로 구한 R이 LCR DCR보다 두 개체 모두 약 6.5% 높다.** 리드선 저항과 전압 표시 계통 오차다. V/I끼리, DCR끼리만 비교해야 한다. R_ref도 R과 같은 방법으로 재야 한다. 1%가 약 2.5 °C이므로 섞으면 15 °C 이상 틀어진다.
- LCR DCR은 집게 접촉에 따라 3% 이상 흔들린다. 같은 조건을 2~3회 반복한다.
- 전원공급기 전압 표시가 0.1 V 단위라 R 기반 온도는 약 ±3 °C다. 코일 단자 전압을 DMM으로 읽는 게 낫다.
- 통전 중 R vs 표면 온도의 겉보기 α가 구리의 1.6~2배로 나온다. 재질 문제가 아니라 **권선이 표면보다 뜨겁기 때문**이다. 표면 온도를 x축으로 두면 기울기가 커 보인다.

한계도 분명했다. 단계당 3~5분만 기다렸고 전압을 내리는 방향이었기 때문에 표면 온도가 계속 내려가는 중이었다. 완전한 정상상태가 아니고, 실제 브라켓에 장착하지도 않았다. 열저항은 장착 조건에 따라 달라진다.

## 분석 도구

측정 파일을 넣으면 그래프와 요약표를 내는 `plot` 명령을 같이 만들었다.

- R vs 표면 온도: 개체별 직선 피팅 → R₂₅, 겉보기 α, R², 구리 α 기준선, LCR DCR 점
- LCR 행이 있으면 DCR / L / Q vs 표면 온도(개체·위치·주파수별). 표면 온도가 2 °C/분보다 빠르게 변하는 점(전원 차단 직후)은 속이 빈 점으로 그리고 피팅에서 뺀다
- V/I 행이 있으면 **정상상태 자동 판정**: V가 0.15 V 넘게 바뀌면 새 단계, 같은 단계 안에서 직전 5분 동안 표면 온도 변화가 0.1 °C/분 이하인 행만 정상상태. 단계별 평균 V·I·R·P·온도, P→0 외삽 기준 저항, 열저항
- 개체별 표면 온도 채널은 `T_surface` 열 → `--map` 옵션 → 자동 탐지(손으로 넣은 T_ref와 가장 잘 맞는 채널) 순서로 찾는다

- 유지력–전류: 힘 게이지 피크 모드
- PWM + 스코프 리플: 잠금·해제·중간 위치, LCR 값과 비교
- 정상상태 재측정: 전압 상승 방향, 단계당 15~30분, 온도 기록을 함께, 실제 브라켓 장착
- 코일 단자 전압 DMM 측정 → V/I vs DCR 6.5% 차이 원인
- 열화상 카메라로 권선·하우징 온도 분포 확인

이날부터 시험 결과를 날짜와 시험 항목 단위로 페이지를 나눠 기록하기 시작했다. 한 페이지에 다 쌓으면 나중에 못 찾는다.
